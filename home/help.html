Which download?

Each app's page has the newest version. Pick one:

DownloadForWhat it is
Download for Windows (setup)Most people on WindowsThe installer. No administrator rights needed. Adds the app to the Start menu.
Portable for Windows (zip)A USB stick, or a PC where you can't installUnzip anywhere and run it. Your settings stay in a data folder next to it, and nothing is left on the PC.
macOS (Apple silicon)KanzonasPDF on a Mac with an M1 or newer chip, macOS 14.4 or newerA disk image: open it and drag the app to Applications. No version for Intel Macs yet.
Linux (AppImage)Linux on a 64-bit PC (Ubuntu 22.04, Debian 12, Fedora 36 or newer)A single file: make it executable and run it. No installation needed.

The Windows warning

The apps aren't code-signed yet, so Windows doesn't recognize them, and every new version counts as new to it. That's why you may see a warning. It doesn't mean anything is wrong:

  1. If your browser asks whether to keep the file, choose Keep.
  2. If Windows says "Windows protected your PC", click More info, then Run anyway.

Only do this with files from these pages or the apps' GitHub releases pages. Every download is built by GitHub's own servers from the public source code, after the automated tests pass. See Checking a download to confirm yours is the real one.

Mac: "Open Anyway" the first time

KanzonasPDF isn't signed by Apple yet, so the first time you open a new version macOS stops it with a message that Apple could not verify it. Click Done (not Move to Trash), then open System Settings > Privacy & Security, scroll down to Security, click Open Anyway next to "KanzonasPDF was blocked", and confirm with your password or Touch ID. After that it opens like any other app. macOS asks again for each new version.

Linux: running the AppImage

  1. Put the AppImage where you keep programs, for example a folder ~/Applications.
  2. Make it executable: right-click it > Properties > Permissions > Allow executing file as program, or run chmod +x on it in a terminal.
  3. Double-click it.

If it doesn't start with an error about FUSE or libfuse.so.2: install FUSE 2 (sudo apt install libfuse2 on Ubuntu 22.04 and Debian 12, sudo apt install libfuse2t64 on Ubuntu 24.04 and later, sudo dnf install fuse-libs on Fedora), or start it with --appimage-extract-and-run after its name.

Updates

Both apps tell you when a new version is out, and you can check any time with Help > Check for updates.... Your settings and work are kept when you update.

  • KanzonasPDF on Windows: download and run the new installer; it replaces the old version. With the portable zip, unzip the new one over the same folder.
  • KanzonasPDF on Linux: Update now downloads the new AppImage, checks it, and puts it in place of the old one.
  • KanzonasPDF on a Mac: download the new disk image, drag KanzonasPDF to Applications and choose Replace.
  • KanzonasCAD: Update now downloads the new version, checks it and installs it over your copy (installer, portable zip and AppImage alike).

Uninstalling

  • Windows (installed): Settings > Apps > Installed apps, find the app, then Uninstall. KanzonasCAD keeps your projects and library in Documents.
  • Portable zip: delete its folder. Nothing else was put on the PC.
  • Mac: drag KanzonasPDF from Applications to the Trash.
  • Linux: delete the AppImage. (KanzonasPDF: if you added it to the applications menu, untick that in File > Preferences > General first.)

Where your settings are

  • Portable zip: in the data folder next to the program.
  • KanzonasPDF on Linux: ~/.config/KanzonasPDF, and signatures, stamps and backups in ~/.local/share/KanzonasPDF.
  • KanzonasPDF on a Mac: ~/Library/Preferences/com.kanzonaspdf.KanzonasPDF.plist, and signatures, stamps and backups in ~/Library/Application Support/KanzonasPDF.
  • KanzonasCAD: your projects are where you save them, and your library is in Documents (KanzonasCAD Library).

Checking a download

Every release lists a SHA-256 checksum for each file, in its notes and in SHA256SUMS.txt. To check yours, compare it with:

  • Windows (PowerShell): Get-FileHash followed by the file name
  • Mac (Terminal): shasum -a 256 followed by the file name
  • Linux (terminal): sha256sum followed by the file name

If the numbers match, you have exactly the file GitHub's servers built.

Still stuck?

Write to support@kanzonas.com, or report a problem on GitHub: KanzonasPDF · KanzonasCAD. Reports on GitHub are public, so please don't attach confidential files. Each app also has a full user manual: press F1.
